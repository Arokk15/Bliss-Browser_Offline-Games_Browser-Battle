# Bliss Browser Offline Games / Browser Battle

See: [:octocat: `Bliss Browser Offline Games`](https://github.com/seanpm2001/Bliss-Browser_Offline-Games/)

Browser Battle is a default game built into Bliss Browser. It is a pun on Bowser Battle, and is similar in style to a Bowser battle from Super Mario Brothers. The premise of the game has not yet been fully defined. Ideas are welcome.

## Ideas

- **Game types**
- - Platformer style (similar to world 8-4 from Super Mario Bros (1985))
- - RPG style (similar to Pokèmon battles)
- **Game mechanics**
- - Pick a specific browser (represented by its logo) to fight against another browser, or entity.
