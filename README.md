## Introduction

Bliss Browser is designed to enhance your browsing experience. As part of this mission, we introduced **Browser Battle**, an offline game that allows users to enjoy gaming without needing an internet connection. This game showcases the capabilities of the Bliss Browser while providing fun and engaging gameplay.

## Features

- **Offline Play**: Enjoy the game without needing an internet connection.
- **User-Friendly Interface**: Simple and intuitive controls make it easy for anyone to play.
- **Engaging Gameplay**: Compete against friends or AI in a thrilling browser battle.
- **Cross-Platform**: Works seamlessly across different devices and operating systems.
- **Open Source**: Contribute to the project and help us improve.
